# 008. MCP registration

Registration connects public schemas to shared services. Existing domain
registrars and payload helpers are available patterns, not required templates.
Choose boundaries that remove repetition without copying auth, relay or
idempotency logic or passing an oversized dependency context.

Current registration tests own names, schemas, defaults, annotations and order.
Preserve transport/errors/media, owner identity and the hidden Store boundary.
The public Gateway inventory must match the current parity checks.

Validate affected registration/backend/transport/OAuth scenarios and capability
parity; use the runbook for release Gateway checks.
