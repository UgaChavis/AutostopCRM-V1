# AutoStop CRM

Follow the active CRM checkout's AGENTS.md and relevant API/MCP contract.
Before applying Manager's M2 rules, select its physical instruction root and
revision by the `Manager instruction roots` section of that checkout's
docs/OPERATIONS_RUNBOOK.md. Read AGENTS.md and docs/agent/modules/M2.md from
the selected Manager root, together with its current journal context. A GitHub
branch link or an installed skill copy does not select the Manager version.

CRM-specific checks and versioned installation are in the runbook. For shared
server update and rollback, follow its Deploy locator to the selected Manager
root's M2 procedure. M1/M2 instructions apply in the user's selected chat;
goal mode is enabled by the user. Publishing source changes does not install
this skill or authorize an application restart.
