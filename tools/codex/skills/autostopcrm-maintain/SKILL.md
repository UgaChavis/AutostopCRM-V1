# AutoStop CRM

Work toward the user's outcome with the approach and scope the evidence supports.
Use the active CRM checkout's AGENTS.md and README.md for project context;
there is no prescribed reading list, task sequence, or commit cadence.
Authorization already given in the task remains valid for its completion.

Keep business behavior in shared services and preserve both browser and Windows
clients. Remove code only after checking its runtime registrations, callers,
deployed data, and compatibility role. A file's name or an audit passing alone
does not prove it unused.

For measured cleanup, performance, or UI work, the optional
[working notes](references/working-notes.md) identify useful boundaries.
Read the current repository operations runbook for release or data repair;
API and MCP guides own their interfaces. Choose relevant checks from current
scripts and CI, and report what changed, measured effects, and remaining gaps.

This package is the versioned source for the installed CRM skill. Installation
instructions are in the repository runbook; edit this source and synchronize
the installed copy rather than maintaining independent instruction sets.
