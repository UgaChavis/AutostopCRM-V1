Money logic:
- cashless repair-order payments are gross incoming amounts
- 15% of each cashless payment is withheld as taxes/fees; 85% covers the order
- cashless amount due is cash_due / 0.85, so paying it closes the order
- invoice "Всего к оплате" is gross cashless invoice total minus all prepayments

Safety:
- GitHub branch autostopcrm-v1 is production source of truth
- verify local, GitHub, and server HEAD before and after deploy
- keep /opt/autostopcrm free of duplicate AutostopVPN source/docs; archive exact untracked copies before cleanup
- safe cleanup candidates are verified Docker build cache, inactive obsolete volumes, old release tarballs, old superseded app rollback backups, and data directories from removed integrations
- keep /root/autostopcrm-backups, /opt/autostop-app-backups recent control copies, active Docker volumes, active nginx/systemd/VPN files, and dirty parallel checkouts
- do not edit JSON state, audit-archive, operator-activity, or cashbox data manually
- run compact_audit_events with --dry-run first; use --apply --backup only after review
- keep server-local .env
- do not commit credentials
- public anonymous writes must stay blocked
- before release from a workstation, run browser_smoke.py and perf_workflows.py --local-temp-server --iterations 3
