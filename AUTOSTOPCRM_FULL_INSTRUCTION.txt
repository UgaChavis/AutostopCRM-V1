AUTOSTOP CRM
Server operator note

This file is copied by deploy.sh to the server desktop when possible.
Keep it short. The canonical runbook is docs/OPERATIONS_RUNBOOK.md.

1. Current paths
- repo: /opt/autostopcrm
- branch: autostopcrm-v1
- compose services: autostopcrm, autostopcrm-telegram-ai
- container data path: /root/.minimal-kanban
- CRM: https://crm.autostopcrm.ru
- MCP: https://crm.autostopcrm.ru/mcp

2. Standard deploy
cd /opt/autostopcrm
AUTOSTOP_DEPLOY_BRANCH=autostopcrm-v1 AUTOSTOP_VERIFY_PUBLIC_HTTPS=1 ./deploy.sh
docker compose ps

3. Main live check
cd /opt/autostopcrm
docker compose exec -T autostopcrm python scripts/check_live_connector.py --strict --site-url https://crm.autostopcrm.ru --expect-https --local-api-url http://127.0.0.1:41731 --mcp-url https://crm.autostopcrm.ru/mcp --operator-username "${AUTOSTOP_SMOKE_OPERATOR_USERNAME:?set smoke username}" --operator-password "${AUTOSTOP_SMOKE_OPERATOR_PASSWORD:?set smoke password}" --expect-admin
Before release from a local workstation, run browser_smoke.py and perf_workflows.py --local-temp-server --iterations 3.

4. Basic diagnostics
cd /opt/autostopcrm
git status --short --branch
git rev-parse --short HEAD
git rev-parse --short origin/autostopcrm-v1
docker compose ps
docker compose logs --tail=200 autostopcrm
docker compose logs --tail=100 autostopcrm-telegram-ai
curl -sS http://127.0.0.1:41731/api/health
python scripts/state_size_report.py --benchmark-iterations 3 --json
python scripts/compact_audit_events.py --dry-run --json

5. HTTPS and nginx checks
nginx -t
systemctl status nginx --no-pager
curl -I https://crm.autostopcrm.ru/
curl -vk -H "Accept: text/event-stream" https://crm.autostopcrm.ru/mcp -o /dev/null

6. Telegram AI
The worker uses long polling and opens no public port.
Required secrets are server-local and must not be committed.
If telegram-ai.env exists as an untracked server file, keep it.

7. Safety
- production source of truth is GitHub branch autostopcrm-v1
- do not edit JSON state manually
- run compact_audit_events only with --dry-run first and --apply --backup after review
- do not remove server-local .env or telegram-ai.env files
- do not commit credentials
- verify local, GitHub, and server HEAD before and after deploy
- public anonymous writes must stay blocked
- cashbox reconciliation is internal diagnostics; operator UI uses the cash journal
- salary release smoke must cover the repair-order executor gear, payroll ledger, and printable salary reconciliation act
